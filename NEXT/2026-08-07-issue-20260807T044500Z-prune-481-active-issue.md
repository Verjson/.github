title: Prune the closed re-review-lane entry from Active Issues
---

`#481` closed with #504, which bridged the `re-review` lane. `CLAUDE.md` loads into every
session, so the entry now costs context in each one while misreporting the state of the work.

Also recorded because it cost a correction: **#292 was closed by accident** by #504's merge. That
commit message read "Does not fix #292, so the re-review skip is still dead", and GitHub's
closing-keyword parser does not understand negation — it matched `fix #292`. Reopened, with the
mechanics noted on the issue. Referring to an issue you are *not* closing needs a bare `#N` with
no keyword adjacent to it; "does not fix #N", "not a fix for #N" and "unlike #N, this fixes…"
all trip it.
