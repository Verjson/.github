title: 'chore(repo): ignore the Serena symbol index'
---

`.serena/` no longer shows up as untracked in `git status`.

It is a per-machine symbol index of this tree, rebuilt on demand — the same
class as `.tokensave/`, which is already ignored directly above it. The whole
directory is ignored rather than the subset Serena's own `.serena/.gitignore`
excludes: that file keeps `project.yml` committable, but a committed index goes
stale without saying so, and the directory is 2.3 MB.

The wider point is that a permanently dirty `git status` is not free. It hides
the signal it exists to carry, so the next person cannot tell uncommitted work
from tooling residue at a glance.
